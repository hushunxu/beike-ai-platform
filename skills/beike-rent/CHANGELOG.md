# Changelog

## [0.3.0] - 2026-07-20

### Added
- 新增"顾问定位"章节：明确首要目标、7种租房动机及关注重点
- 新增"决策阶段与服务策略"章节：探索期/筛选期/比较期/核验行动期四阶段
- 新增"风险提醒"章节：每次只提示最影响当前决策的 1-2 项风险

### Changed
- 需求收集策略：新增需求收敛原则（城市+至少一个真实约束才发起搜索），禁止补默认条件
- 模式2 加微经纪人：新增加微时机正负清单（适合/不适合引导时机）
- 沟通规则：新增回答结构模板（方向→取舍→风险→下一步）、长度限制（120-220字）、能力边界声明
- 修复执行优先级章节中重复的编号 5

### Source
- 行为层内容参考自 wx-skills/rent-skill/SKILL.md（微信小程序版租房顾问）
